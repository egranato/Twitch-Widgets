OBS Setup Guide

How to Add Browser Sources to OBS:

  1. Right-click your scene -> Add Source -> Browser
  2. Copy the full URL from this desktop app (use "Copy URL" buttons)
  3. Paste into OBS browser source URL field and confirm
  4. Set width x height to recommended dimensions (see route cards)
  5. For /audio-manager only: Check "Control audio via OBS" to enable audio output
  6. For all other routes: Keep audio disabled

Audio Configuration: Only the /audio-manager source should have audio enabled. All other browser sources must have audio disabled to prevent overlapping sounds.

/full Complete Overlay

All-in-one overlay with chat and alerts combined.

  • Recommended Size: 1920x1080 (full screen)
  • Audio: Disabled
  • Use Case: Full-screen overlay for main game scene
/chat Chat Widget

Live chat messages scrolling as viewers type.

  • Recommended Size: 650x760 (side panel)
  • Audio: Disabled
  • Use Case: Floating chat panel visible to stream
/alerts Follow & Subscribe Alerts

Animated notifications for follows, subscriptions, and cheers.

  • Recommended Size: 700x400 (centered)
  • Audio: Disabled (audio comes from /audio-manager)
  • Use Case: Main alert display; position in center of screen
/audio-manager Audio Queue (Critical)

Central audio playback for all alerts: TTS, cheers, subscriptions, follows.

  • Size: 1x1 (invisible; audio-only)
  • Audio: Must enable
  • Use Case: Only source with audio enabled; all sounds play through here

Critical Setup: Add this as a persistent browser source, set size to 1x1 (or hide off-screen), and enable "Control audio via OBS." This is the only source that should have audio enabled.

/auth Twitch Authentication

Complete Twitch OAuth authorization for bot and API access.

  • Type: One-time auth flow (not a persistent source)
  • Use Case: Click "Open" to authorize in browser; required once at setup

OBS Video Reward Mappings

Map each Twitch channel point reward title to an OBS source so redemptions trigger your local video source.

OBS Setup Checklist
  1. In OBS, create a group named Channel Point Rewards (or keep your existing one with that exact name).
  2. Add each reward video as a source inside that group (for example: Loser, Dumb Animal, Yipee).
  3. For hybrid rewards, add both sources in OBS (for example GIF source + overlay source) and register both below.
  4. Make sure each source name in OBS exactly matches the OBS Source Name values you register below.
  5. In each media source settings, enable Restart playback when source becomes active.
  6. In each media source settings, enable Show nothing when playback ends.
  7. In your scene list, click the source eyeball icon so each reward source starts hidden by default.
  8. For audio in hybrid rewards, add the audio clip as an OBS media source in this same group and include that source name in the mapping fields below.
  9. Create matching Twitch reward titles and register those exact titles below.
